# Components

`src/components/` contains reusable presentation and interaction. Keep components focused, typed,
and accessible. Put external data access in services and domain-specific logic in helpers. Group
new components by domain when a child area already exists; use the nearest child instructions for
cards, contact, and layout.

Use Tailwind and DaisyUI as described by the project-conventions skill. Review changed components
in the real route at desktop and mobile widths when their UI is user-facing.
